# SLE_TCW

随机润滑方程的两个独立研究目录：

| 目录 | 内容 |
|---|---|
| [tcw/](tcw/README.md) | 热毛细波谱、线性理论对照、绘图脚本、已有图表与 Basilisk TCW 求解器 |
| [film_rupture/](film_rupture/README.md) | 液膜破碎 ls 等效0.2：4种厚度×5种子及1条旧版对照，共21条轨迹；参数、源码、批处理与 hmin–t / V 监测 |

TCW 原有内容整体移入 `tcw/`；在该目录内执行原 README 的命令，已有相对路径保持成立。绘图脚本中的外部原始数据目录仍需按本机数据位置设置。液膜破碎批次仅完成部署与监测，V 守恒及数值/物理收敛尚未验收；两目录的滑移参数约定见各自源码与说明。
