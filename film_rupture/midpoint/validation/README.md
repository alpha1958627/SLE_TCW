## 原部署实现门槛

- 参考算子最大绝对差：漂移约1.12e-15，噪声3.47e-18，Jacobian作用7.11e-15，单步1.47e-14。
- 8高度×2dt 的16项轨迹与逐字节续算门槛通过。
- MPI 1/4/16/64 在100步 t30 的保存场逐字节一致（见 TCW_PASS.json 的 MPI 部分）。不是任意长时间或任意编译器逐字节保证。
- 原 SIPF 运行环境 Python3.6.8/NumPy1.19.5/SciPy1.5.4，源与实际库独立绑定。二进制不随源码发布，也不宣称跨平台二进制相同。

## 同节点速度

单位为代码时间/墙钟秒；同一独占节点、cap .3、相同 seed，暖机 t3 后计时 t3→33，无异步原场输出，每设置2次。**native1/Basilisk1 才是相同核数比较**。native 只加速算子，但该短窗仍通常更快。

16MPI 是已测 Basilisk 配置中最快，64MPI 反而慢；这不是任意节点/临破碎阶段速度保证。Python native 和 Basilisk 对应的进程布局、线性求解器栈不同，不能将核数差掩盖为纯实现加速。
