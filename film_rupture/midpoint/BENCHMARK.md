# 同一组16条轨迹：总墙时

以下四行来自 **2026-10-27 g1 同节点基准**，不是四种时间格式，也不是单条轨迹的耗时。

| 实现 | 计算资源 | 16条总墙时 / s | 相对1核加速 |
|---|---|---:|---:|
| SLE-SMID-FV-C99 | CPU 1核，16条串行 | 192.36 | 1.00× |
| SLE-SMID-FV-C99 | CPU 4核 MPI，轨迹并行 | 47.99 | 4.01× |
| SLE-SMID-FV-CUDA | A100 80GB GPU0 + 1主机线程，批量16条 | **34.00** | 5.66× |
| SLE-SMID-FV-C99 | CPU 16核 MPI，轨迹并行 | **12.23** | 15.72× |

**本基准最快的是16核CPU。** GPU比4核CPU快1.41倍，但16核CPU比GPU快2.78倍。这里的C99实现仍由Python/SciPy承担Newton/GMRES/FFT，不能称为全C求解器或纯Python程序。Basilisk不在这四行内。

## 相同工作量与计时边界

- 16个seed为2026102201–2026102216；H=1、h0=1.2、N=64、cap=.3、phi_ref=.01、ell_ref=.2、hstar=0，FP64。
- 每条先从t=0预热至3；计时区间 **t_code=3→300**，全16条完成后停止计时。包括兼容CPU布朗噪声、噪声上传、步长控制和必要同步；最终场文件输出在计时区间外。不是生产作业从提交到归档的时间。
- 同一g1节点：Xeon Platinum 8375C，GPU为A100 80GB PCIe GPU0；节点共享，另一块GPU已有工作，本测试没有使用它。每配置一次测量，没有重复试验置信区间。
- CPU三行来自同一次基准记录，在后续GPU融合测试中复用；CSV中不把复用记录当第二次测量。CPU MPI是一条轨迹一个rank，非单场空间分解。
- GPU场、残差、Krylov向量和回代在显存；CPU生成原PCG64布朗路径，保留严格seed配对。GPU并非零CPU同步程序。

GPU批量1/4/16/64条耗时16.26/20.09/34.00/87.18秒。B64中CPU噪声约68.61秒，占78.7%，GPU尚未饱和；`87.18/64`是吞吐摊销，不能称单条延迟1.36秒。

## 配对与数值核验

CPU/GPU共同16seed最大场差9.20e-14；独立CPU重算的末步最大物理残差7.08e-12，小于1e-10；续算、独立lane拒绝、近阈值事件细分与错误seed拒收通过。完整T300基准未发生平膜破碎，属于固定窗随访，不提供MFPT数据。

TCW需要注明参考：共同16seed相对**连续正则模有限时间理论**，低段0<r<=8组均约+1.508%，高段24<r<=46约+71.354%，CPU和GPU重合。先前约百分之一的高段偏差使用同N64离散线性参考；二者不是同一基准。端到端加速不证明连续空间TCW、破碎时间或MFPT收敛。
