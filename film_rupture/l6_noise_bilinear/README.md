# SLE-SPLIT-FV-BASILISK：noise=L6-bilinear

本目录与[随机中点版](../midpoint/README.md)分开。它在旧 Basilisk 分步程序上改变噪声空间表示，**没有移植随机中点**。

两面分量分别在 L6 交错面上生成 Gaussian 噪声，周期双线性插值至 L7/L8，通量归一化始终用 Delta6=L/64。不新增细网格随机数，不按插值后的方差再归一。L6 走原坐标调用，逐字节对照曾通过。这是固定空间噪声截止测试，不是空间白噪声的联合网格极限。

## 源码与参数

- `noise_l6_bilinear.h`：完整插值与周期噪声定义。
- `noise_probe.c`：无 Basilisk 依赖的节点一致性、交错权重、周期接缝自测。
- `source_h0.5_L6.c` 至 `source_h0.6_L8.c`：6份已部署源码，保持原字节；对应90条为 h.5/.6×L6/L7/L8×分档/.01/.003×5seed。
- `provenance.json`：本包逐文件 SHA256。

源文件名的 h0 是外部参数，不是实际传给初态的 H。主程序参数是：

```text
program seed dt_cap step_limit ell_code initial_H tiered
```

原测试初值 **H=1**、ell_code=.2/h0、hstar=0；source 内 A=.0013159/h0²、phi=.01/h0²、L=100/h0。必须显式传入滑移和初值，不能直接使用源码默认 slip=0/H=h0。分档设 tiered=1、cap=.1，固定 .01/.003 设 tiered=0。示意（编译环境需与原 Basilisk/view/glutils 兼容）：

```sh
gcc -std=c99 noise_probe.c -lm -o noise_probe
./noise_probe
# 已构建 source_h0.5_L6 对应程序后，在全新工作目录：
/path/to/h05_L6 2026112101 .01 200000000 .4 1.0 0
```

不同 dt/分档跨网格未做共同布朗时间增量耦合；同 seed 不能当逐路径强收敛检验。
