# v4：附壁液膜多重网格与一致的乘性噪声通量

本分支修复 y 索引已校正的附壁多重网格程序中，热噪声残差缺少面厚度因子的问题。`residual_layer()` 现在使用

```c
No.x[] = Noise1.x[] * (h[] + h[-1]) / 2.;
```

它与 `relax_layer()` 中的面厚度系数保持一致。对通量 `C H_f^(3/2)`，线性化是 `1.5 C sqrt(H_k) H_new - 0.5 C H_k^(3/2)`。原残差漏掉了第一项中的 `H_new`。`legacy_control.c` 仅用于复现这一缺陷的回归对照，不能作为修复后的科学计算入口。

## 模型与网格

本分支是可变迁移率 `H^3` 的附壁模型：`A=0.2`、`hs=0.1`、`m=n=3`、`dd=5`、周期域 `L=100`，化学势 `-laplacian(H)+A/H^3-A*hs^2/H^5`。它是此附壁 MG 支线的 v4；仓库的中点、CUDA 与其他物理参数支线仍各有自己的入口。

固定 level 7（128²）计算网格；两个独立面通道在 level 6（64²）产生高斯噪声，按各自交错面位置做周期双线性插值。归一化使用粗网格间距和时间步，不对细网格点值方差重新归一化。初值为可复现的小扰动。保持 y 邻居索引修复，初始化求解参数；本驱动没有 AMR、厚度裁剪或质量补量。

默认固定步长仍是 `dt=0.001`。命令行可指定 0.001 的整数倍（至0.3），该接口范围不代表所有步长都已通过验证。本版本没有自适应拒步控制器。时间格式沿用该 MG 支线的隐式后向 Euler；此修复解决残差/松弛器一致性，不单独确定乘性噪声的统计解释或平衡分布。

## 复算

需要支持 OpenMP 的 Basilisk `qcc`、GCC、Python 3；复算脚本仅用 Python 标准库。

```sh
export BASILISK=/path/to/basilisk/src
bash build.sh
mkdir test_run
cd test_run
OMP_NUM_THREADS=4 OMP_PROC_BIND=true OMP_PLACES=cores \
  ../layer_v4 0.001 300 20 result.json 0.001
```

参数依次为 `phi measured_steps warmup_steps result_json [dt]`。此例包含20步热身和300步计时，到 `t=0.32`；输出完整历史与末场。计时包括粗噪声生成、插值、场复制和积分，不含独立方程残差、统计、输出与启动。

在至少4个可用物理核的分配内运行 `python3 run_validation.py`，可复算全部36次比较。各步长把同一0.001基步的布朗增量求和，保证比较同一随机路径、相同初态和相同物理终点。`run_trial.py` 另外比较强噪声下三种步长至 `t=3`。

## 四核短窗验证

128²计算/64²噪声，phi为0、1e-4、1e-3；原缺陷对照和 v4 每配置交替重复3次。以下为 phi=1e-3 的中位计时，误差参照 v4 的 dt=0.001，定义为末场差的 RMS 除以参照场的厚度涨落 RMS。

| 版本 | dt | ms/步 | t/墙钟小时 | 同路径场误差 |
|---|---:|---:|---:|---:|
| 原缺陷对照 | 0.001 | 18.855 | 190.93 | 1.009% |
| v4 | 0.001 | 17.335 | 207.67 | 参照 |
| v4 | 0.005 | 19.585 | 919.05 | 1.364% |
| v4 | 0.01 | 27.241 | 1321.54 | 2.836% |

v4 的0.005/0.01吞吐分别约为默认步长的4.43/6.36倍，每步本身更贵。完整结果见 [benchmark.csv](benchmark.csv)，检查摘要见 [validation.json](validation.json)。默认热组完整方程残差降至约5e-16；全部 v4 步长/噪声组的最大残差4.82e-11，最大相对质量漂移1.91e-14。原缺陷对照的热组最大残差约1.37e-4。源码SHA在 [provenance.json](provenance.json) 中记录。

这些是近乎平膜、有限时间窗和单一随机驱动的验证。更大步长改变时间离散；当前结果不能证明 TCW 平衡谱或破碎首达时间收敛。
